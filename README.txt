├── css/
│   └── estilos.css

    └── galeria/

## Para editar

1. Cambia "Nombre Apellido" y los textos de index.html.
2. Reemplaza las imágenes dentro de img/.
3. Coloca el video de portada como img/hero.mp4.
4. Para cada proyecto, modifica data-category:
   - foto
   - video
   - arte
5. Agrega nuevas tarjetas copiando un <article class="project-card">.
6. Para una galería individual, puedes crear después páginas:
   proyecto-01.html, proyecto-02.html, etc.
7. Si dispones de Bauer Bodoni en .woff2, colócala en una carpeta fonts/
   y activa el bloque @font-face de estilos.css.
